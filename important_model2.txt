Model 2 is trained first on the prepared PTB-XL beat-level data because these beat segments already have disease labels.
At this stage, the beats are extracted during preprocessing with a simple peak detector, so Model 2 can learn the task “beat segment -> disease class” independently.
Later, after Model 1 is trained, Model 1 won't directly give the disease prediction. It will only predict R-peak locations.
Those predicted peak locations will then be used to cut new beat segments from the ECG signal, and these beat segments will be passed into Model 2 for disease classification.
Because Model 1 is trained on 360 Hz MIT-BIH data and Model 2 is trained on 100 Hz PTB-XL beat segments,
the final integration must handle the sampling-rate difference. A safe approach is to convert Model 1 peak indices into time,
resample or use a 100 Hz version of the signal, convert the peak times back into 100 Hz indices, and then cut the same 70-sample beat windows for Model 2.
The full connected pipeline therefore still needs to be evaluated again after both models are trained, because beat segments extracted from Model 1 predicted peaks may be slightly different from the preprocessing-based beat segments used during Model 2 training.

Example code for the integration:

# Model 1 works on 360 Hz signal
predicted_peaks_360 = model1.predict(signal_360)

# convert peak sample positions to seconds
peak_times = predicted_peaks_360 / 360

# resample the ECG signal to 100 Hz
signal_100 = resample_signal(signal_360, old_fs=360, new_fs=100)

# convert peak times to 100 Hz sample positions
predicted_peaks_100 = (peak_times * 100).astype(int)

# cut model 2 beat windows
beats = extract_beat_windows(
    signal=signal_100,
    peaks=predicted_peaks_100,
    fs=100,
    before_sec=0.25,
    after_sec=0.45
)

# Model 2 classifies these beats
predictions = model2.predict(beats)
